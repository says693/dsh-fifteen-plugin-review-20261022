# 右下角那只小玩偶，数字一个都没错，却把我的发送键吃了

晚上十点，你终于把那段话改顺了。三百多字，在输入框里，光标在末尾一闪一闪。你按了一下右下角那个蓝色的发送箭头——没有动静。

你以为是自己没点准，又点了一下。还是没有。屏幕右边那只一直蹲着的小玩偶，忽然换了个表情，头顶冒出"打招呼"，还顺手弹出一块统计面板。你的三百字，还老老实实躺在输入框里。

这是我第一次用它时发生的事。

## 它到底做了什么

`dsh-token-pet` 想在 DSH 的网页里放一只常驻的小宠物。它会动，会随你的状态换表情；旁边挂一个小窗，告诉你这会儿"上下文"用了多少、这个会话一共烧了多少 token、跨会话累计多少。

"上下文"这个词先解释一下：AI 每次回答你之前，得把你的历史对话、系统说明、工具清单一起读一遍，这些加起来有容量上限，就像一张书桌，摊满就没地方放了。插件做的事，就是把"桌面还剩多少空"画成一个百分比给你看。

我装的是 npm 上那个 `0.4.2` 版。

## 我第一次用它

装完刷新，小玩偶真的出现了——右下角，一只会呼吸的绿色小人，下面是"上下文 50%"。

我造了几段假对话，把 token 用量算死了再去对：某段会话我手算是 95200 个 token，点开它的明细，显示"21k 输入 / 1.2k 输出 / 71k 缓存读 / 2.0k 缓存写"，四个数加起来正好 95200。上下文占用我算 50000÷100000＝50%，它也写 50%。跨会话的总账我算 2,223,600，它写 2.2M。连"缓存读 942000"这种细节都一位不差。

我特意喂了一段夸张的数据：窗口只有 10 万，却塞了 200 万个 token。我本以为会看到 2000% 这种笑话，结果它老老实实夹到了 100%，还配了句"快满啦！建议压缩一下上下文"。

那一刻我是有点意外的——它比我预想的认真。

## 好用的地方

它不靠网络活着。我把所有外部请求都掐断，小玩偶照样在，百分比照样对，因为那些数本来就是 DSH 自己算好递给它的。唯一受影响的是跨会话账本那块，它会老老实实写"读取失败"，给你一个重试按钮，不转圈、不假装。

打开一个空会话，它不硬凑出"0%"糊弄你，而是显示"上下文窗口读取中"和一横杠。

我让它开了五分多钟，页面上的元素数量从头到尾没变过（795 个），内存还从 96.9MB 掉回 90.7MB。滚动的时候采了两百多帧，最慢一帧 7.4 毫秒，一次卡顿都没有。

那只玩偶还是用一千多张连起来的图做的动画，全部打包在插件里，所以不存在"图片加载失败显示一个破图标"这种事。

## 让人卡住的地方

**就是开头那一下。** 我花了不少功夫才弄明白：玩偶外面套着一层透明的、比它大得多的"玻璃"——实际是 248×217 的一块隐形区域，而玩偶本身只有 120×175。你点发送按钮的时候，手指其实是点在玻璃上，玻璃把这下点击收走了，转手交给了玩偶。

我把窗口调成 1440、1000、760、600 四种宽度，全都一样。最夸张的时候，我在这块玻璃上均匀撒了 550 个点，其中 346 个落在看得见的玩偶之外——也就是说，你点到"空气"也会被它吃掉。

这不是你的错，是它这里没做好。绕过办法有两个：把玩偶拖到离输入框远一点的地方（我拖到左上角就好了），或者按回车发送而不是点按钮。

还有一处会让人困惑。小窗最上面那行一直写着"模型未知"，可是翻到"模型"那一页，明明清清楚楚写着模型名字。我扒了一下，那行字只认一种叫"上下文时间线"的数据，而这版 DSH 根本没提供这份数据，所以它永远是"未知"。数据其实有，只是那一路没接上。

第三处小别扭：我点了"首次建立索引"，它变成"索引已就绪 · 0 个已索引"，可同一屏下面还写着"首次建立历史索引后显示"。已就绪了，又说要建了才有——我盯着看了半天，才在设置页最底下找到一句"当前宿主不支持趋势索引"。

## 我没办法验证的部分

它还有提示词增强、完成提示音、成本估算、皮肤导入这几样。这些要么得真的调一次模型，要么得有一段真实回复，要么得我自己准备一个皮肤压缩包。我按约定一次模型都没调，所以这几样我只能说：没测，不知道好不好用。

另外我只在 DSH 0.2.0-rc.2 这一版上试过，作者文档里提到过给更老版本留的退路，我没有条件回测。

还有件事你可能也会遇到：这个包在 npm 上登记的仓库，和另一个同名仓库不是同一份东西。两个我都装了，另一个版本能正常显示，还有日期和天气；天气接口在 0.2.0 这版上接不通，它会显示"天气不可用"，不崩也不空白。所以你从不同地方装到的"同名插件"，长相可能完全不一样。

## 给想装的人一句话

如果你只是想随时知道"桌子还剩多少空"，它算得又准又稳，值得装；装完先把那只玩偶拖到远离发送按钮的角落，再开始用——等你被吃掉一次三百字，就会明白为什么要先拖它。
