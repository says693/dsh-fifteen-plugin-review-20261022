# 我在右边装了一条"书签栏"，它一直没出现

周六下午，你在翻一段很长的对话——七八轮来回，往上翻要滑好久。你想找"第三轮我问过的那个报错"，只能靠滚轮一路摸回去，滑到一半就忘了在找什么。有人做了个插件，说能在右侧挂一条竖着的目录，每一轮一句话，点一下就跳过去，像书签。

我装的就是它。装完，没有书签栏，什么都没有。

## 它到底做了什么

`dsh-turn-index` 想给你的是一条"轮次索引"，像一本书的目录页：你问的每句话都在右侧占一行，前面带编号；点那一行，页面平滑滚到那轮开头；你往下读时，"当前这一轮"跟着亮起来。

它不联网、不上传、也不读写你的文件——这点我看了代码，是真的。

## 我第一次用它

装的时候一切正常，命令跑完没有一句抱怨。重启，刷新。我盯着右侧看了几秒——空白。没有细条，没有小圆点，连一条线都没有。我以为页面没加载完，又等五秒；刷新；把宿主整个关掉重开一个。还是空白。

我怀疑自己装错了，因为宿主的"插件"页明明白白写着：已安装 1，dsh-turn-index。它在那里，只是没露面。

接着做了几件笨办法：翻遍整页找有没有藏起来的方块（一个都没有）；打开控制台找红色报错（一条都没有）；去看它的样式表有没有被加载——这次有了。说明它真跑起来了，连画界面的"颜料"都调好了，只是最后没画。

## 好用的地方

界面没机会出现，所以"用起来爽不爽"我没资格评价。但有两件事它做对了：一是安装，一条命令、零配置，没让我填 API Key；二是它很干净——只读当前会话，只往浏览器的小储物柜（localStorage，浏览器给每个网站的一小块储物柜）里存一个"收起/展开"的偏好。

## 让人卡住的地方

**它没出现，而且不告诉你为什么。** 这是最难受的一种失败——不是报错，是沉默。你没法判断是自己装错了、忘了重启、还是它坏了。

我花了不少功夫才找到原因，说出来很短：它去问宿主"我现在在看哪个会话"，用的那个问法在这版宿主上永远得不到答案，于是它每次都决定"那我不显示了"。这不是你的错，是它这里没做好。

顺带一个小问题：它没声明自己支持哪个版本的宿主。所以装的时候不会收到提醒，问题要等你打开页面才发现。

**踩坑了怎么办**：在 0.2 这一代宿主上先别装，等作者修。已经装了的，卸载用 `dsh plugin --profile web remove dsh-turn-index`，再重启宿主、按 `Ctrl+Shift+R` 硬刷新。

## 我没办法验证的部分

它承诺的那些"用起来"的细节，我一个都没测到——界面根本没出来。滚动时目录会不会跟着亮、点一下跳得准不准、收起之后下次还记不记得，这些都得先有那条栏才有得看。我只能说：没有对象可以观察，不能说它坏了，也不能说它好。

另外我只在一版宿主上试过，作者写的支持版本更早，那版上好不好用我没条件回测。用的也是我自己造的几段对话，不是真跟模型聊出来的——这不影响"它有没有出现"，但确实不是真实使用场景。

## 给想装的人一句话

如果你手上是旧那一代宿主，它值得一试——"给长对话加个目录"这个想法很实在，而且它做得干净、不打扰。如果你已经在新这一代，先别装：装了也看不到东西，而且它不会告诉你为什么。
