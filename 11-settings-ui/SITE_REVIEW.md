# 那个总挡住聊天记录的设置窗口，终于可以听你的了

周日晚上十点半，你在改小组作业。左边是资料，右边是聊天记录，中间那个设置窗口正好盖在你最需要看的那段字上。你想挪开它，拖不动；想缩小，边缘也没有能拉的地方。只好关掉它，改两行，再打开。

这是我装上 dsh-settings-ui 之前的日常。它不加新功能，只是来把那个窗口还给你。

## 它到底做了什么

打开宿主左下角的「设置」，左侧导航会多出一项「设置界面」。点进去，右边一小片面板，只有三件事：窗口多大、背景多不透、背景什么颜色。

## 我第一次用它

里面没有开关，也没有保存按钮，只有一排写着尺寸的小方块。我点了「大（1080×780）」，窗口当场长胖。没有闪烁，没有"请稍候"，也没有"保存成功"——它就是变了。

我愣了一下，又点「全屏」，窗口贴着四边铺开，圆角也没了。再点「默认」，它缩回去，干干净净，像什么都没发生过。点错了再点回来就行。

背景那栏也好玩。滑块从 100 往下拉，窗口变透明，后面聊天区的字一点点透出来。拉到 70 最好看，像隔着一层磨砂玻璃。推回 100 又变回白墙，临时写进去的样式也被清掉。

再往下有「纯色」，选它会冒出两个小色块，一个管亮色，一个管暗色。你把亮色换成橙色再切到深色，窗口不会变成一片橙，它自动换成暗色那一格。

## 好用的地方

**关掉再打开，东西还在原处。** 设成大、70%、橙色，关窗再打开，还是那样。整页刷新一样，把宿主关掉重开，也一样。

很多插件会把设置塞进 localStorage（浏览器给每个网站的一小块储物柜，换个浏览器就空了）。这个没这么干：它交给宿主，存进 profile（同一台电脑上并存的几套独立账本）里的配置文件。换浏览器不丢，换 profile 就是另一套——这两件事一起发生，不是毛病。

**「恢复默认」是真恢复。** 有些软件只改个样子，下次打开又回来。这个是真回：窗口回 800×800，透明度回 100，背景回主题色，插件加的样式清空成 0 字节，磁盘那份也回默认。

**小屏幕不乱。** 缩到 600 像素宽，面板自己收成 552×752，方块折成四行，没有横向滚动条。

**深色下看得清。** 我用对比度量过（字的颜色和背景的明暗差距，数字越大越好认），深色里说明小字 5.02，主标签 6.64，正文到 4.5 就算达标。

**它很安静。** 十几次操作，控制台一条红色报错都没有。

## 让人卡住的地方

然后我点到了「自定义」。这里能自己输宽高。我想设 900×600，点进宽度框，`Ctrl+A`，按 `Delete`，敲 `9`、`0`、`0`。

输入框里出现的是 `48000`。

再试一遍：删光后敲 `9` 变 `4809`，再敲一个 `0` 变 `48090`——每个数字都被接在原来那串后面，全选根本没生效。高度栏也一样，原本 960，敲 `600`，得到 `360600`。

**这不是你的错，是它这里没做好。** 我查了原因：那个框是浏览器专门收数字的一种输入框，而浏览器对这种框不支持"选中一段文字"——我一调用选中它就报错。选不中，全选等于没按。更麻烦的是插件每敲一个键就立刻存一次，每按一下都往硬盘写个荒唐数字。

绕过它有三个办法，我都试过能用：**粘贴**（`Ctrl+A` 后直接粘 `900`，会成功，窗口真的变 900 宽）、**方向键**（按上下箭头一格一格走）、**退格键**（一路退到下限）。

还有第二个问题：这框只防小不防大。输 `0` 没事，被夹到 480；但输 `-100` 变成 `480100`，输 `99999` 变成 `4809999`，而且真会写进配置文件。窗口没被撑爆，是因为样式里有一句"最宽不超过屏幕"替它兜住了视觉——数据层没兜住。

还有个看不见的缺口：不透明度滑块和两个色块都没给读屏软件念的名字，用读屏的人听到的是三个没名字的"滑块""颜色选择器"。键盘那一半倒做得好：方块是真按钮，能 Tab 到、Enter 能选。

## 我没办法验证的部分

**它一开始可能"打不开"。** 首次启动宿主会先弹「添加一个 API Key」，这时点左下「设置」毫无反应——我一开始也以为自己点错了。点掉「稍后配置」就正常了。这是宿主的脾气，不是插件的问题。

**悬浮球和图片背景，这版本里没有。** 我扫过页面和源码，找不到痕迹，也没有上传图片的入口。不是坏了，是本来就没有。

**拖动没用。** 窗口是宿主在屏幕中央摆好的，插件只管它多大、不管它在哪。

**滑块按住拖动，我测得不太稳。** 有时拖到一半松手会弹回 100%，但点滑轨和键盘上下键都稳。我不确定是插件的问题还是我这边模拟鼠标的局限，所以不写成结论。

**我只在一个宿主版本上试过。** 作者提过更老的版本和桌面版，我没环境回测；也没配真实账号，没在真实对话里跑过。

## 给想装的人一句话

如果你每天都在用设置窗口、它老挡着你——装，它会立刻让你舒服，设置不会丢，想反悔点一下「恢复默认」就回去了。

如果你只是偶尔开一次设置，或者正需要用键盘精确输入自定义尺寸，可以先等等：那个数字框现在只能靠粘贴绕过。
